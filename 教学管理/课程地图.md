# 课程地图

更新日期：2026-09-19。依据：[本校教学计划](../《python与金融大数据分析》教学计划.doc)、[1—6周教案](../《Python与金融大数据分析》教案（1-6周）.doc)和教材配套材料。以下是计划结构，不代表实际已授课。

## 课程定位与学情

本校计划面向财富管理专业学生，先修《数字素养与技能》，绝大多数编程零基础。学生熟悉办公软件，对金融业务有感性认知，需通过直观结果、小步操作、分层练习建立分析能力。

教材配套大纲面向大数据技术类专业，先修《Python编程基础》。两者先修条件不同，因此需补充列表、字典、索引、条件表达式、函数调用等必要语法，不能直接套用教材节奏。

本校计划每周4学时，共64学时。计划文字提出理论与上机1:3；教材大纲为理论28、实验36学时，两者需区分使用。

## 第一周的两种材料口径

本校第一周教案描述了读取客户CSV、筛选信用分、清洗排序和画图的综合任务。实际已有课堂代码主要是print、f-string、input、int/float/str转换、运算符及年龄练习，课堂笔记强调激活pydata、切换目录和启动Jupyter。

教师于2026-09-12确认实际第一周已教print、input、int/float/str和简单数学运算，第二周继续基础语法。以该反馈作为实际教学依据，不认定学生已学Pandas。已授内容的具体掌握程度仍通过课堂检查确认。

## 案例依赖关系

1. 粮食：数组创建 → 年份与产量对应 → 统计、筛选及增长分析。时间升降序必须先检查。
2. 工业：读取月度长表 → 日期转换 → 按产品和年份聚合 → 增长分析。产品名称含不同计量单位，不能跨单位求总产量。
3. 电商：订单表和商品表 → 按组合键合并 → 清洗、标准化、分箱 → 可视化。项目4输出和项目5输入需核对文件版本。
4. 书籍：原始数据 → 预处理 → 图表 → 聚类、分类、回归。项目7已有预处理数据，但项目6输出衔接需验证。
5. 餐饮：客户信息和订单 → 最近消费、频次、金额等特征 → K-Means分群 → 决策树/SVM流失分类。适合后续迁移到金融客户教学场景，迁移方案尚未实施。
