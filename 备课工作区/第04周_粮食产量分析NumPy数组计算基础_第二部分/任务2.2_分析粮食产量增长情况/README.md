## 教学建议

基础必做：二维数组、逐元素算术、比较与all/any、按行/按列广播，重点解释`*`与`@`的区别。矩阵乘法规则、共轭转置、求逆及复数例子按学情作为拓展。

建议先预测再运行：①二维数组`*`与`@`；②形状`(4, 3)+(3,)`；③形状`(4, 3)+(4, 1)`；④修改`asarray`结果与修改`copy`结果。评价以正确结果和运算、形状、共享内存的解释为准。Notebook为教师演示材料，内含输出；学生独立预测应先自行填写。
