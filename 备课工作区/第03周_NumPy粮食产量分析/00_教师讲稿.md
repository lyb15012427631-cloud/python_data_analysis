## 第一学时：一组数如何一起计算

导入：“这10年粮食产量最高的是哪年？期末比期初高，是否代表每年都增加？”先展示CSV前两列，不要求学生理解其余16列。说明主任务单位万吨，数据止于2023年。

先修短题：`[10,20,30][1]`、`[10,20,30][1:3]`、`120>110`分别是什么？答案20、[20,30]、True。若多人不会，先用三个格子标0、1、2并补切片和比较，暂缓reshape扩展。

01—02：解释“库是别人整理好的工具；import导入，np是简称”。先让学生猜列表乘2，再对照数组乘2。“原来要循环三次，现在一条表达式逐项做”。跟练改成每项加10。查看shape是`(3,)`，只有一条轴；dtype统一为float，不要求背位宽。

03—04：用黑板画3行2列，每行年份、每列地区。强调嵌套列表的每行长度一致。取`a[0,1]`、`a[:,1]`、`a[:2,:]`，每次先指格子再敲代码。reshape不改变元素个数；不将年份产量组合表整体求均值。收题1作为即时检查。

## 第二学时：从小表到教材CSV

05：板书同单位模拟表`[[10,20],[30,40],[50,60]]`，让学生先按列加出90、120，再按行加出30、70、110。讲“axis指被消去的维度”，不只背横向纵向。题2每个结果都要口述对象。

06：比较得到布尔数组，True位置保留。先输出条件，再输出年份，最后输出产量。将`>`改为`>=`观察边界；多条件分别加括号并用&。

07：教师提供读取代码并逐个解释delimiter、skiprows、usecols、dtype、encoding。读到的是文字，“2023年”先replace，再int；产量列astype(float)。普通for衔接上周，不要求列表推导式。`Path`只是跨平台组织路径的工具，学生本周不必独立设计路径系统。

先打印原前三行，问“新年份在哪一头？”再用argsort对两数组同步排序。不能只排序产量。08按年份范围筛选，不按“文件前10行”盲取。检查题3应得到75行原记录、10行目标记录、首2014末2023。

## 第三学时：让每个结果回答一个问题

09：均值回答“这10年平均每年多少”，累计回答“10年一共多少”，标准差描述这些年度值离均值的离散程度。总体标准差ddof=0；不在本课展开推断统计。argmax是位置，years对应位置才是年份。用布尔条件处理并列极值，避免把位置9当作2009年。

10：高于均值先建条件，再取years和yields。排名只建立独立rank，不改时间数组。学生题4先独立完成一个统计，再交换核对单位。

11：先板书模拟2021—2023年[100,120,110]：2022增长20，2023增长-10；同比20%、-8.33%。让学生指出分母为何不是当年110。再解释[1:]与[:-1]成对对齐，结果对应years[1:]。10个观测只构成9个相邻差。真实选定期内基数均为正；其他数据若基期为0应标记无法定义，不输出无穷大当有效结果。

提问：“2016和2018下降，是否可以说逐年持续上升？”要求改成“期末高于期初，但期间存在下降”。从数据只能描述变化，不能直接断言天气、政策的因果。

## 常见错误与排查

| 现象 | 检查与引导 |
|---|---|
| No module named numpy | 看当前内核与已配置课程环境是否一致，先切换正确内核 |
| 数据文件不存在 | 打印Path.cwd()；Notebook应和data目录同级，解压完整学生包后打开 |
| 中文解码错误 | 用UTF-8-sig；不要随意用Excel另存覆盖配发文件 |
| 无法把“2023年”转float | 先去“年”，年份列单独转int |
| reshape报错 | 原元素数量是否等于目标行数×列数 |
| 布尔条件报歧义 | 数组用&，两侧条件加括号；不要用普通and |
| 均值中混入年份 | 只对yields统计，不对两列表整体统计 |
| 增长方向反了 | 检查years首末，确认升序；检查上年作分母 |
| 数组长度不同 | mask和排序索引必须同时应用于年份、产量 |
| NameError或旧输出误导 | 重启内核并按顺序运行；本周单元之间有依赖 |
