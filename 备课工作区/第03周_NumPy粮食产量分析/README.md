4. 分发“第三周_学生资源.zip”：学生练习、速查表、数据说明、CSV与启动说明。教师答案未包含在学生压缩包内。
5. 第四学时完成[学生综合任务](02_学生练习.ipynb)，题1—6基础100分，拓展不计分。12为结果导出模板。
6. 教师用[独立答案](03_教师参考答案.ipynb)及[结果核对表](06_教师结果核对表.md)讲评。

## 输入、依赖与输出

- Python 3、NumPy；不依赖pandas、绘图库或网络服务。本次不安装任何依赖，不更改全局环境。
- 输入：data/粮食产量年度数据.csv，为教材原件的逐字节副本。
- 基础演示输出到屏幕；示例12将增长结果写至outputs/2015至2023年增长分析.csv。其他选做代码不写外部文件。
- Notebook、答案各自按顺序执行，不保证每个单元可脱离前文独立运行。
- 主任务为2014—2023年10年，原文件1949—2023年75年；增长量与增长率对应2015—2023年9个间隔。
- 不对教材原件运行代码。知识准备先于综合任务，未把教材全部高级函数塞入本周基础目标。
