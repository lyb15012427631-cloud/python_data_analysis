# 第三周学生资源使用说明

适用第三周，目标：用NumPy读取、筛选并分析粮食产量。需要已有课程Python环境和NumPy。

1. 将压缩包完整解压到自己的课程目录，保留data文件夹。
2. 激活老师指定的课程环境，进入解压后的文件夹，启动Jupyter Notebook，选对应Python内核。
3. 打开02_学生练习.ipynb，从第一个单元运行；先跟随老师学习数组，再完成题1—6。按Shift+Enter运行单元。
4. 代码写在TODO处，文字解释写在Markdown单元。先读04_NumPy速查表.md和05_数据与来源说明.md；本次数据单位为万吨，主任务2014—2023年。
5. 保存为班级_姓名_第三周.ipynb，保留代码、输出和报告；提交截止日期由老师指定。

输入data/粮食产量年度数据.csv；一般结果直接显示在Notebook。若使用老师提供的导出模板，只写outputs目录。不要覆盖CSV。报文件不存在先检查Notebook和data是否同级。报NameError先从头运行。
本包不含教师答案；模拟小表不是历史真实产量。代码本机验证情况由教师包记录，Windows机房运行仍须课前核对。
