4. 教师使用[参考答案](03_教师参考答案.ipynb)讲评；不要把整个教师包直接作为学生任务包。
5. 查看[验证记录](验证记录.md)了解本次运行环境和边界检查结果。

基础必做：比较与逻辑、if/elif/else、一维列表与索引、for/range、while、def与参数/return、len/sum/min/max/round/abs/sorted，以及筛选统计综合应用。
拓展：enumerate、zip、break/continue、默认参数与关键字参数。
本周目标是结束进入数据分析库之前的核心语法补充，不宣称覆盖Python全部语法。字典、模块导入等可在具体库案例中按需补讲。
