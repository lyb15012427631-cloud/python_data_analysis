# 第二周基础函数速查表

所有金额为模拟数据，单位元。先理解输入和返回结果，再记函数名。

| 名称 | 用途 | 示例 | 结果/提醒 |
|---|---|---|---|
| print | 显示 | print(10) | 显示10，函数本身返回None |
| input | 读取输入 | input("金额：") | 返回str，参与计算前转换 |
| int / float / str | 类型转换 | float("12.5") | 12.5；int("12.5")不能直接转换 |
| type | 查看类型 | type(10) | int类型 |
| len | 元素个数 | len([0, 20, 40]) | 3，0也计数 |
| sum | 总和 | sum([0, 20, 40]) | 60 |
| min / max | 最值 | max([0, 20, 40]) | 40，空列表须先处理 |
| round | 保留小数位的数值结果 | round(10/3, 2) | 3.33，不保证固定显示两位 |
| abs | 绝对值 | abs(-20) | 20，大小不含方向 |
| sorted | 新的排序列表 | sorted([20, 0, 40], reverse=True) | [40, 20, 0]，原列表不变 |
| range | 循环范围 | list(range(1, 4)) | [1, 2, 3] |
| enumerate（选学） | 序号和值 | enumerate([20, 40], start=1) | for循环逐个取得(1,20)、(2,40) |
| zip（选学） | 两组数据配对 | zip(["A", "B"], [20, 40]) | 默认遇较短一组结束，先核对长度和对应关系 |

列表方法`.append(value)`把值加入原列表，通常单独写一行；不要写`values = values.append(10)`，append返回None。

## 语法骨架

```python
amount = 120
if amount < 100:
    print("小额")
elif amount < 500:
    print("中额")
else:
    print("大额")

total = 0
for value in [20, 40]:
    total = total + value

balance = 0
while balance < 300:
    balance = balance + 100

def add_amount(a, b):
    return a + b

result = add_amount(20, 40)
print(result)
```

`=`赋值，`==`比较；`and`都满足、`or`至少一个满足、`not`取反；冒号和缩进决定代码属于哪一块。
`return`结束本次函数调用并交回结果；`break`结束所在循环；`continue`跳过本轮余下代码后二次判断/进入下一轮。
基础分析流程：先判断数据有效性，再统计；计算平均值或最值前检查是否为空。
