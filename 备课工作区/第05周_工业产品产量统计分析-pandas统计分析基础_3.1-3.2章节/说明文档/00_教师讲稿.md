# 第五周教师讲稿：3.1读取与3.2基本情况

适用五班统一教学，4×40=160分钟，不含课间。课程依据：根目录本校教学计划、1—6周教案第4—6周相关目标，以及教师本次指定的知识准备3.1、3.2。原计划第5周pandas常用方法仅作参照，本次以指定章节为准。2.2已获教师确认讲完；2.3实际完成情况未反馈，不预设学生已掌握全部统计。

## 目标、重点与先修

- 能读入CSV并用shape、columns、head验证读取是否正确，认识一列Series与二维DataFrame。
- 能区分loc标签和iloc位置，完成单列、多列、行片段和条件筛选。
- 能在副本增删改而不污染统计基线；解释mean、median、count、describe与value_counts。
- 能限定产品、年份、单位后分析产量，区分缺失与0，写出含对象和单位的结论。

重点：读取后核查、loc/iloc、统计口径。难点：整数标签与位置恰好相同造成的混淆、频数不等于销售量、有效月份均值不等于完整年度指标。
先修：列表与字典、下标从0开始、左闭右开切片、==条件、函数参数、NumPy的shape。无需先修数据库。

开课3题：`[10,20,30][1]`是多少；字典`{'数量':[3,5]}`的键是什么；`[10,20,30][0:2]`有几个数。若答错集中，用本课第1节预留缓冲补讲；不由旧备课材料推断掌握。

describe只必讲count、mean、min、50%、max；25%/75%与样本std含义简述，可留速查表。原文件删行后再统计，本版改为全量基线，结果差异要明确说明。

## 常见错误和排查

| 现象 | 先查什么 | 处理 |
|---|---|---|
| FileNotFoundError | 工作目录与data位置 | 从本包启动Jupyter，保留文件夹结构 |
| KeyError列名 | columns、中文空格及单位 | 复制核对后的完整列名，不改原CSV |
| 筛选结果0行 | 商品ID dtype、比较值类型 | 本文件整数比较；显式string读取则用字符串 |
| iloc接条件报错 | 条件是不是Series | 改loc；位置数组路线才用to_numpy |
| 修改未影响原表 | 是否链式赋值、是否目标为副本 | 明确修改对象，使用单步loc |
| 统计值与课本不同 | 是否删过行、改过类别 | 重读salesdata基线；edited只演示 |
| Excel多出Unnamed列 | 写出时是否index=False | 只修新导出流程，检查回读 |
| 均值看似偏低 | 是否把缺失填0或混合单位 | 保留缺失、限定产品与单位 |

课前：检查内核版本与文件可读；重启内核顺序执行新Notebook；Windows机房另行验证。
课后反思：待教师反馈实际完成题号、共性错误和学生解释证据后填写。
