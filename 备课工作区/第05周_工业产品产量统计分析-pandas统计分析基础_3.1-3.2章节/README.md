## 启动与依赖

把整个第五周文件夹放在可写目录，保留data等子目录位置。在Anaconda Prompt激活学校现有课程环境（以本机实际环境名为准），`cd`到本包后运行`jupyter notebook`。Notebook选择同一环境内核；先执行开头单元确认pandas版本。

核心：Python、pandas；3.2原示例29另用NumPy（可略）。Excel需要openpyxl；SQL选做使用MySQL教学服务器、PyMySQL及SQLAlchemy；连接配置见“选做内容”内模板。新版MySQL案例尚未连接服务器实跑。
课堂不自动安装或升级依赖。教师课前检查`import pandas as pd; print(pd.__version__)`及`import openpyxl`。Windows机房尚未实测，不把本机结果当成机房验证。

运行顺序：每份Notebook独立从上到下，先3.1再3.2再练习。公共路径设置支持从第五周根目录或Notebook所在子目录运行；输入统一读取根目录data，输出统一写入根目录outputs。输入只读data；导出只写outputs，反复运行会更新本包同名演示导出文件。教材tmp目录不写入。

本包的pandas最新版审查以2026-10-24核对的3.1.0为准，见[官方3.1发布说明](https://pandas.pydata.org/pandas-docs/stable/whatsnew/v3.1.0.html)。
