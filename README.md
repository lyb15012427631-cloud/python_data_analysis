## 如何提出教学任务

可以直接描述教学需求，例如：

- “准备第二周Python基础，学生刚学过input和数据类型，需要教师讲稿和学生练习。”
- “把第六周工业案例补充成金融行业分析，保留原案例，使用小数据讲清分组统计。”
- “本周学生切片理解较慢，请记录共同反馈，并调整下次课的复习安排。”

提供周次、班级、学生已学内容、可用课时和希望交付的材料会更准确；已有记录不需要重复提供。

## 每次备课的工作过程

查阅课程地图和实际进度 → 核对本节原始材料及数据 → 在备课工作区制作材料 → 按需验证代码 → 更新管理记录。

新课时目录按任务逐步建立，可包含教师讲稿、学生练习、教师答案、数据和案例说明。教师已确认机房课程虚拟环境配置完成，每节课激活后使用Jupyter Notebook。本周基础代码无需额外依赖；后续库案例所需依赖仍按具体任务核对，不将原有environment.yml视为全学期环境的完整证明。
